# Wan Muhammad Ashraf — Personal Resume Website

A clean, responsive personal resume/portfolio website built with pure HTML, CSS, and JavaScript.

🔗 **Live Site:** [https://pacca1412.github.io/test-01/](https://pacca1412.github.io/test-01/)

---

## ✨ Features

- **Responsive Design** — Looks great on desktop, tablet, and mobile
- **Dark Mode** — Toggle between light and dark themes (preference saved)
- **Scroll Animations** — Smooth reveal animations as you scroll
- **Downloadable Resume** — One-click PDF download
- **Contact Form** — Ready for backend integration
- **Back-to-Top Button** — Quick navigation for long pages
- **Zero Dependencies** — Pure HTML, CSS, and vanilla JavaScript

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/pacca1412/test-01.git
   ```

2. **Open locally**
   ```bash
   cd test-01
   ```
   Open `index.html` in your browser.

3. **Deploy to GitHub Pages**
   - Go to **Settings → Pages** in your GitHub repository
   - Set source to **Deploy from a branch**
   - Select **main** branch and **/ (root)** folder
   - Click **Save**

## 🛠️ Customisation

- Edit `index.html` to update content (name, experience, skills, etc.)
- Edit `styles.css` to change colours, fonts, or layout
- Replace `assets/Wan_Muhammad_Ashraf_Resume.pdf` with your latest resume
